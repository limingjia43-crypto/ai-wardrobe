## 双视口完整流程

### Desktop 1440px

✅ 添加物品 → 保存并继续添加 → 打开右侧箱子 Drawer → 选择分类 → 打开分类 → Sticky Detail Panel → 名称搜索 → 查看位置 → 更新位置 → 设置中修改分类名称和常用位置名称。

### Mobile 390px

✅ 添加物品（AI 失败模拟）→ 保存并继续添加 → 打开全屏箱子 → 点击分类 → 打开双列分类 → Bottom Sheet 详情 → 名称搜索 → 查看位置 → 更新位置 → 设置中修改分类名称和常用位置名称。

两种视口均无横向溢出，核心任务不依赖 Desktop 拖拽。

## 本轮修复

1. 连续录入：增加捕获阶段的提交意图与隐藏字段，避免“保存并继续添加”被错误当作普通保存。
2. 位置确认：`confirmLocation` 只更新 `location_confirmed_at`；UNCERTAIN 状态不再显示不适用的“位置正确 / 未找到”操作。
3. 编辑图片：将透明文件输入设置为独立、真实可点击的覆盖控件，确保鼠标、触控和自动化均能打开文件选择器。
